# داریک — نسخه ۱ (کامل)

اپ مدیریت مالی شخصی، به‌صورت PWA برای آیفون.

## چه چیزهایی دارد
- **حساب‌ها:** بانکی، بروکر، کیف پول و نقد. موجودی اولیه، تطبیق موجودی، بایگانی، و میانگین قیمت خرید تتر.
- **ثبت سریع:** هزینه و درآمد (مبلغ، بعد لمس دسته)، انتقال بین حساب‌ها، خرید و فروش تتر با نرخ و کارمزد، تگ، تراکنش آماده.
- **ترید:** ثبت روزانه سود یا ضرر، «جلسه دیشب»، «ترید نکردم».
- **وام:** یادآوری سررسید روی صفحه خانه، پرداخت با یک لمس، مانده بدهی.
- **هدف پس‌انداز:** زیرهدف، اتصال به حساب، زمان رسیدن با روند فعلی، و مبلغ لازم در ماه.
- **گزارش‌ها:** خلاصه ماه، خرج بر اساس دسته (با رفتن به داخل هر دسته)، گزارش ترید با تحلیل شب‌های هفته و اثر نرخ تتر، روند ۶ ماهه، فیلتر حساب و تگ.
- **پیش‌بینی:** بازه خرج تا آخر ماه، سود لازم، دوام بدون درآمد، و سه سناریو.
- **صفحه خانه:** نمودار کل دارایی (هفته، ماه، ۳ ماه) با لمس.
- **دسته‌ها:** ساختن، تغییر اسم، آیکون و رنگ.
- قیمت تتر از نوبیتکس، پشتیبان‌گیری، و کار بدون اینترنت.

## فایل‌ها چه کار می‌کنند
| فایل | کار |
|---|---|
| `index.html` | اسکلت صفحه. همه چیز داخل این فایل ساخته می‌شه |
| `css/app.css` | کل ظاهر: رنگ‌ها، کارت‌ها، دکمه‌ها، انیمیشن‌ها |
| `js/app.js` | نقطه شروع: بارگذاری داده‌ها، تب‌بار، جابه‌جایی بین صفحه‌ها |
| `js/store.js` | داده‌های اپ در حافظه، و همه کارهای ثبت، حذف و ویرایش |
| `js/db.js` | ذخیره روی گوشی (IndexedDB) و خروجی پشتیبان |
| `js/ledger.js` | محاسبات مالی: موجودی، کل دارایی، خلاصه ماه |
| `js/jalali.js` | تبدیل تاریخ میلادی و شمسی |
| `js/money.js` | نمایش عددها: تومان، تتر، اعداد فارسی و تاریخ |
| `js/seed.js` | دسته‌ها و حساب‌های پیش‌فرض بار اول |
| `js/price.js` | گرفتن قیمت تتر از نوبیتکس |
| `js/backup.js` | ساختن و برگرداندن فایل پشتیبان |
| `js/icons.js` | آیکون‌ها (داخل خود اپ) |
| `js/ui.js` | ابزارهای ظاهری: برگه پایین، پیغام، پس‌زمینه دلاری |
| `js/views/*.js` | هر صفحه یک فایل: خانه، ثبت سریع، ترید، تراکنش‌ها، حساب‌ها، بیشتر، گزارش‌ها، وام، هدف، دسته‌ها |
| `design/icon.svg` | فایل اصلی آیکون اپ (قابل ویرایش)؛ `icon-1024.png` نسخه‌ی بزرگش |
| `sw.js` | نگه‌داشتن فایل‌ها روی گوشی برای کار بدون اینترنت |
| `manifest.webmanifest` | اسم و آیکون اپ برای نصب روی صفحه اصلی |

**فونت‌ها:** وزیرمتن برای متن‌ها و لاله‌زار برای عددهای بزرگ و عنوان‌ها.

**قانون مهم داده‌ها:** مبلغ‌های تومانی به «ریال» و به‌صورت عدد صحیح ذخیره می‌شن و فقط موقع نمایش به تومان تبدیل می‌شن. تتر با اعشار ذخیره می‌شه.

## اجرا روی کامپیوتر (برای امتحان)
اپ باید از یه «سرور» باز بشه. باز کردن مستقیم `index.html` کار نمی‌کنه.
1. پایتون نصب کن.
2. توی پوشه `darik` یه ترمینال باز کن و بزن: `python -m http.server 8000`
3. توی مرورگر برو به `http://localhost:8000`

## انتشار روی اینترنت با GitHub Pages (رایگان)
1. توی github.com یه حساب بساز و یه repository جدید به اسم `darik` بساز. Public باشه.
2. با «Add file → Upload files» همه فایل‌ها و پوشه‌های داخل `darik` رو آپلود کن، نه خود پوشه رو.
3. برو به Settings → Pages، Branch رو بذار روی `main` و `/ (root)`، بعد Save.
4. بعد از یکی دو دقیقه، آدرس اپ می‌شه: `https://اسم-کاربری-تو.github.io/darik/`

## نصب روی آیفون
1. آدرس اپ رو توی **Safari** باز کن (کروم نه).
2. دکمه Share رو بزن، بعد **Add to Home Screen**.
3. از روی آیکون «داریک» بازش کن.

## آپدیت کردن اپ
وقتی فایل‌ها عوض شدن، توی `sw.js` عدد `VERSION` رو یکی بالا ببر (مثلاً `darik-v3`) و دوباره آپلود کن. اپ رو یه بار ببند و باز کن.
